# Current Economics of OpenAI

## Facts

* ChatGPT Plus: **~₹2,000/month**
* Codex Plus usage has both **5-hour** and **weekly** limits.
* GPT-5.6 Sol API pricing used for comparison:

  * Input: **$4 / 1M tokens**
  * Cached input: **$0.40 / 1M**
  * Output: **$20 / 1M**
* OpenAI does not publish the exact token equivalent of Plus Codex limits.

## Estimated 5-Hour Usage

Representative workload:

| Tokens                 |  API cost |
| ---------------------- | --------: |
| 3.0M cached input      |     $1.20 |
| 0.8M input             |     $3.20 |
| 0.15M output/reasoning |     $3.00 |
| **3.95M total**        | **$7.40** |

Working estimate for exhausting one 5-hour allowance:

**~$6–$8 at API list prices**

## Monthly Estimate

Estimated weekly limit:

**~6–7 full 5-hour-equivalent allowances/week**

Monthly equivalent:

**6–7 × 4.33 = ~26–30 allowances/month**

API-equivalent monthly value:

* **26 × $6 = $156**
* **30 × $8 = $240**

Central estimate:

**~$200/month**

At **$1 ≈ ₹90**:

**$156–$240 ≈ ₹14,000–₹21,600**

Compared with a **~₹2,000/month** Plus subscription:

**~7–11× the subscription price at API list prices**

## Key Findings

* Estimated maximum heavy Codex usage: **~$156–$240/month in API-list-price equivalent**
* Central estimate: **~$200/month**
* Plus price: **~₹2,000/month**
* Estimated API-price-equivalent value: **~7–11× subscription price**
* The result is approximate because neither the exact weekly token allowance nor the exact token composition of a fully consumed 5-hour window is published.
